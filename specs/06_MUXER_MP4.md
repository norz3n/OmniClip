# 06. Упаковка в MP4 (Fast Streaming MP4 Remuxer)

## 1. Концепция
Сброс повтора из памяти на диск должен происходить **мгновенно** (< 300 мс для файла объёмом 250 МБ на SSD/NVMe).
Поэтому процедура **не должна перекодировать ни одного байта**. Она выполняет чистое мультиплексирование (remuxing) уже сжатых пакетов H.264 и AAC в контейнер ISO Base Media File Format (MP4).

## 2. Варианты реализации

### Вариант A: Использование Windows Media Foundation Sink Writer (IMFSinkWriter)
Media Foundation предоставляет встроенный быстрый упаковщик `IMFSinkWriter`, не требующий ручной генерации MP4-атомов:
1. Создание: `MFCreateSinkWriterFromURL(output_path, None, None, &mut sink_writer)`.
2. Конфигурация:
   - Добавление видеопотока с типом `MFVideoFormat_H264`.
   - Добавление аудиопотока с типом `MFVideoFormat_AAC`.
3. Упаковка:
   - В цикле считываются элементы из слепка кольцевого буфера (`Snapshot`).
   - Для каждого элемента создаётся `IMFSample` и передаётся в `sink_writer.WriteSample(stream_index, &sample)`.
4. Финализация:
   - Вызов `sink_writer.Finalize()`.
   - Занимает минимальное время и формирует стандартный валидный MP4-файл.

### Вариант B: Легковесный Rust MP4 Muxer (например, `mp4` crate)
Чистая реализация в Rust без COM-обёрток SinkWriter:
- Запись атомов `ftyp`, `moov`, `mdat`.
- Потоковая запись `mdat` напрямую в `BufWriter<File>`.
- Сборка таблиц сэмплов `stts` (тайминги), `stss` (ключевые кадры), `stsz` (размеры) и запись `moov` атома.
- Использование режима **FastStart** (перемещение `moov` в начало файла) для мгновенного превью в проводнике Windows и плеерах.

## 3. Наименование файлов и директория сохранения
* По умолчанию: `%USERPROFILE%\Videos\OmniClip\Replay_YYYY-MM-DD_HH-MM-SS.mp4`.
* Создание целевой папки при первом старте.
* При успешной записи: звуковое или всплывающее уведомление Windows (Tray balloon / Toast notification).
