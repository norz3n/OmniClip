# 07. Промпт для передачи AI-агенту (Handoff Prompt)

Скопируйте текст ниже и вставьте его в диалог новому агенту:

```markdown
Привет! Мы разрабатываем OmniClip — сверхлёгкую альтернативу NVIDIA ShadowPlay и AMD ReLive на Rust под Windows.
В репозитории уже сформирована подробная спецификация в папке `specs/`, файл `SPECS.md`, а также файл текущего состояния `MEMORY.md`.

ОБЯЗАТЕЛЬНЫЙ РЕГЛАМЕНТ РАБОТЫ С ПАМЯТЬЮ (MEMORY.md):
1. ПЕРВЫМ ДЕЛОМ прочитай файл `MEMORY.md` — там зафиксировано текущее состояние, принятые решения и следующий шаг.
2. В КОНЦЕ КАЖДОГО ЭТАПА / СЕССИИ обязательно обновляй `MEMORY.md` актуальным статусом, выполненными изменениями и следующими шагами.
(Правило зафиксировано в `.agents/rules/memory.md`).

Ознакомься со спецификациями:
- `MEMORY.md` (Текущее состояние и ближайший шаг)
- `SPECS.md` (Главная архитектурная спецификация)
- `specs/01_ARCHITECTURE.md` (Zero-Copy конвейер, потоки, тайминги QPC)
- `specs/02_CAPTURE_DXGI.md` (Захват через IDXGIOutputDuplication, Direct3D 11)
- `specs/03_ENCODER_MFT.md` (Аппаратный Media Foundation H.264 MFT энкодер)
- `specs/04_RING_BUFFER.md` (Кольцевой буфер в RAM, выравнивание по ключевым кадрам IDR)
- `specs/05_AUDIO_WASAPI.md` (Захват системного звука WASAPI Loopback, сжатие AAC)
- `specs/06_MUXER_MP4.md` (Быстрый сброс из памяти в MP4 без перекодирования)

Ключевые инженерные требования:
1. Windows-only (Windows 10/11), язык Rust (2021).
2. Zero-Copy: текстуры D3D11 не считываются на CPU, кодируются прямо в GPU через IMFDXGIDeviceManager.
3. Без тяжёлых внешних зависимостей (никакого стороннего FFmpeg, всё на чистом Win32/Media Foundation через crate windows).
4. Начинаем реализацию согласно разделу "Следующие шаги" в `MEMORY.md` (Cargo.toml и Этап 1: DXGI Desktop Duplication + Direct3D 11).

Прочитай `MEMORY.md`, спецификацию и приступай к реализации.
```
