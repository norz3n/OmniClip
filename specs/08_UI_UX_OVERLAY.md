# 08. Спецификация UI/UX: Игровой оверлей и панель управления (Material Design 3)

## 1. Концепция и цели

OmniClip — сверхлегковесная система повторов, требующая современного, ненавязчивого и отзывчивого интерфейса в стиле **Nvidia ShadowPlay (GeForce Experience)** и **AMD Software (ReLive)**, адаптированного под дизайн-систему **Google Material Design 3 (Material You)**.

### Ключевые требования UX:
1. **Zero Game Distraction**: В обычном режиме оверлей невидим, отображается только компактный HUD-индикатор статуса в углу экрана (опционально отключаемый).
2. **Мгновенный вызов по хоткею**: Глобальная комбинация клавиш (`Alt+Z` по умолчанию) вызывает полноэкранный затемненный хаб управления поверх любого активного окна или игры без минимизации игры.
3. **Бесшовная передача ввода (Input Passthrough)**: Когда оверлей скрыт, все события мыши и клавиатуры проходят сквозь прозрачный слой без задержек. При активации оверлея управление перехватывается.
4. **Toast-уведомления (Snackbars)**: Мгновенное подтверждение сохранения повтора по `Alt+F10` с карточкой предпросмотра, таймингом и кнопкой быстрого перехода к файлу в Проводнике.

## 2. Дизайн-система: Material Design 3 / Material You

Интерфейс строится строго по спецификации **Material Design 3 (M3)** с динамической генерацией тональных палитр и скруглений.

### 2.1. Цветовая палитра (Dark Theme / OLED-Friendly)

Базовый цвет затравки (Seed Color): `#4C6BFF` (Cyber Indigo / Omni Blue) или `#00E5FF` (Neon Cyan).

| Роль тона (M3 Token) | HEX (Темная тема) | Описание / Применение |
|---|---|---|
| **Primary** | `#ADC6FF` | Акцентные кнопки сохранения, активные тумблеры, фокус |
| **On Primary** | `#002E69` | Текст и иконки на primary-элементах |
| **Primary Container** | `#264483` | Плашки активного состояния записи |
| **On Primary Container** | `#D8E2FF` | Текст на активных контейнерах |
| **Surface** | `#111318` | Базовый глубокий фон диалогов |
| **Surface Dim / Scrim** | `#00000080` | Полупрозрачное затемнение игры (Backdrop blur) |
| **Surface Container** | `#1E2025` | Основные карточки (Replay, Record, Audio) |
| **Surface Container High** | `#282A2F` | Выделенные элементы, выпадающие списки |
| **Surface Container Highest**| `#33353A` | Ховер-состояния, разделители |
| **Outline / Outline Variant**| `#8E9099` / `#44474E` | Тонкие границы карточек и инпутов (1px) |
| **Error / On Error** | `#FFB4AB` / `#690005` | Предупреждения о нехватке памяти/диска |

### 2.2. Формы и скругления (Shape Tokens)

* **Extra Small (4px)**: Тултипы, бейджи индикации FPS/Audio.
* **Small (8px)**: Кнопки-чипы (Filter chips), слайдеры, поля ввода TOML-параметров.
* **Medium (12px)**: Контекстные меню, выпадающие панели настроек.
* **Large (16px)**: Основные функциональные карточки оверлея (Hub Cards).
* **Extra Large (28px)**: Главные диалоговые окна и снекбары уведомлений.
* **Full (9999px / Pill)**: Плавающие кнопки действий (FAB), чипы быстрого сохранения.

### 2.3. Поверхности и глубина (Elevation & Glassmorphism)

В отличие от классического M3 для Android, в контексте игрового оверлея для Windows применяется **Mica / Acrylic-эффект** через DirectComposition:
* **Background Blur**: `DWM BlurBehind` / акриловое размытие фона (16-32px gaussian blur).
* **Surface Tint**: Заливка полупрозрачными тонами `Surface Container` с альфа-каналом `85%`.
* **State Layers**: Hover (+8% Primary tint), Pressed (+12% Primary tint), Focused (+12% Outline).

### 2.4. Типографика (Type Scale)

Основной шрифт: **Segoe UI Variable** (нативный для Windows 11) или **Roboto Flex / Inter**.
* **Display Small (36sp / Medium)**: Цифровой таймер длительности буфера ("01:00").
* **Headline Small (24sp / SemiBold)**: Заголовки основных карточек ("Мгновенный повтор").
* **Title Medium (16sp / Medium)**: Названия параметров конфигурации.
* **Body Medium (14sp / Regular)**: Вспомогательные описания, статус битрейта и FPS.
* **Label Large (14sp / SemiBold)**: Текст на кнопках (Caps не используется, M3 Title Case).

## 3. Архитектура и сценарии экранов

### 3.1. Hub-экран (Alt+Z Fullscreen Overlay)

Центральный хаб состоит из 3 ключевых карточек с горизонтальным размещением в центре экрана:

```
+-------------------------------------------------------------------------+
|  [Logo OmniClip]                         Status: Active (480MB RAM) [X] |
|                                                                         |
|   +-------------------+  +-------------------+  +-------------------+   |
|   | МГНОВЕННЫЙ ПОВТОР |  |      ЗАПИСЬ       |  |     НАСТРОЙКИ     |   |
|   |                   |  |                   |  |                   |   |
|   |    ( ( o ) )      |  |        [ o ]      |  |        [ * ]      |   |
|   |                   |  |                   |  |                   |   |
|   |  Статус: ВКЛ      |  |  Ручной старт/стоп|  |  Видео, Звук,     |   |
|   |  Длина: 60 сек    |  |  (Alt+F9)         |  |  Горячие клавиши  |   |
|   |                   |  |                   |  |                   |   |
|   |  [ Сохранить ]    |  |  [ Начать ]       |  |  [ Открыть ]      |   |
|   |   ( Alt+F10 )     |  |                   |  |                   |   |
|   +-------------------+  +-------------------+  +-------------------+   |
|                                                                         |
|   [Микрофон: Вкл (100%)]       [Динамики: 48kHz]      [Папка: D:\Replays]
+-------------------------------------------------------------------------+
```

1. **Карточка 1: «Мгновенный повтор» (Instant Replay)**:
   - Переключатель (M3 Switch): Включение/выключение фонового кольцевого буфера.
   - Большая кнопка-пилюля: «Сохранить (Alt+F10)».
   - Интерактивный слайдер длительности (15с, 30с, 60с, 2м, 5м, 10м) с динамической оценкой потребления ОЗУ ("~480 MB").
2. **Карточка 2: «Ручная запись» (Manual Record)**:
   - Старт непрерывной записи без ограничения кольцевого буфера (`Alt+F9`).
3. **Карточка 3: «Настройки» (Quick Settings)**:
   - Разрешение (Native / 1080p / 1440p / 4K).
   - Целевой FPS (60 / 120 / 144 / 240).
   - Битрейт видео (15 — 80 Мбит/с).
   - Настройка микрофона (выбор устройства, ползунок громкости, режим Push-to-Talk / Always On).

### 3.2. Внутриигровой HUD (In-Game Corner Badge)

Располагается в настраиваемом углу (по умолчанию: правый верхний):
* **Мини-бейдж (M3 Assist Chip)**:
  - Зеленый пульсирующий индикатор `●` (Идет фоновая запись).
  - Иконка микрофона: перечеркнутый (Muted) или активный с динамическим уровнем громкости.
  - Анимация спиннера во время асинхронного сброса MP4 на диск фоновым воркером `omniclip-disk-writer`.

### 3.3. Toast-уведомление (M3 Elevated Snackbar)

Появляется в правом верхнем углу при успешном сохранении повтора:
* **Заголовок**: «Повтор сохранен» (Title Small).
* **Тело**: `Replay_1773489123.mp4` • 60 сек • 36.4 МБ (Body Small).
* **Кнопки действий**:
  - `Показать в папке` (Текстовая кнопка M3 с вызовом `explorer /select,`).
  - `Закрыть` (Иконка крестика).
* **Автоматическое исчезновение**: через 4 секунды с плавной анимацией скольжения и затухания.

## 4. Технологический стек реализации под Windows (Rust)

С учетом строгих требований к производительности OmniClip (минимальный footprint, отсутствие Electron/Chromium, Zero Input Lag):

### 4.1. Архитектура оконного слоя
* **Topmost Borderless Window**: Окно Win32 с флагами `WS_EX_TOPMOST | WS_EX_LAYERED | WS_EX_TOOLWINDOW`.
* **Hit-Test Passthrough**:
  - В неактивном режиме: стиль `WS_EX_TRANSPARENT`, события мыши не блокируются.
  - В активном режиме (`Alt+Z`): стиль снимается, окно принимает фокус и ввод.

### 4.2. Графический бэкенд рендеринга оверлея
* **Вариант А (Direct2D / DirectComposition — максимальная легкость)**:
  - Рендеринг поверх существующего D3D11-устройства через `ID2D1DeviceContext`.
  - Потребление памяти: **< 10 МБ ОЗУ**. Время холодного открытия: **< 5 мс**.
* **Вариант Б (egui / Slint с кастомной темой M3)**:
  - Компилируемый Rust UI-фреймворк с полной поддержкой реактивного состояния.
  - Быстрая декларативная верстка всех карточек и анимаций.

## 5. План поэтапной реализации

1. **Фаза 1: Уведомления и статус-HUD**:
   - Реализация M3 Toast-окна при сохранении файла через `Alt+F10`.
   - Добавление отключаемого HUD-индикатора в угол экрана.
2. **Фаза 2: Оконный фреймворк оверлея**:
   - Создание прозрачного Topmost-окна с переключением по `Alt+Z`.
   - Захват и освобождение фокуса клавиатуры и мыши.
3. **Фаза 3: Компоненты Material 3 Hub**:
   - Отрисовка карточек с тональными темами, кнопками-пилюлями и слайдерами.
   - Двусторонняя привязка UI к глобальной конфигурации `Config`.
4. **Фаза 4: Системный трей и интеграция**:
   - Иконка в системном трее (`Shell_NotifyIconW`) с быстрым вызовом оверлея.
